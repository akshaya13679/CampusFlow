# CampusFlow — Interactive Student Planner 🎓

A responsive, interactive to-do list dashboard for engineering students. This version is a **single-file website**: all HTML, CSS and JavaScript are included in `index.html`.

## Features
- Add, edit, delete, and complete tasks
- Due date, optional time, notes, category, and priority
- Search, filter by priority/category, and sort tasks
- Today, upcoming, completed, and dashboard views
- Progress dashboard
- Ready-made engineering student activities and random idea generator
- Dark mode
- Saves tasks in this browser with localStorage
- Responsive desktop and mobile layout

## Run it
Open `index.html` in a modern browser. No installation or server is needed.

## Publish with GitHub Pages
1. Create a public GitHub repository named `CampusFlow`.
2. Upload `index.html` and `README.md` to the root of the `main` branch.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for deployment and open the URL shown in the Pages section.

**Note:** Tasks are saved in the browser on the device where you use the site. They do not sync between devices or users because this version has no backend.
